# Sistema de Migración Libro 209

Sistema de migración específico para el Libro 209 con control centralizado en SQL Server.

## Archivos

- **create_sql_server_tables.py**: Script para generar SQL de creación de tablas en SQL Server
- **libro209_migrator.py**: Script principal de migración (Python)
- **libro209_config.env**: Plantilla de configuración de variables de entorno
- **libro209_cron.example**: Ejemplos de configuración para cron jobs
- **README.md**: Documentación completa del sistema

Ver README.md para instrucciones detalladas de instalación y configuración.
